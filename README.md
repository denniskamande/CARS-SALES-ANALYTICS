#  Cars Sales Data  Analytics

## Project Overview

An end-to-end data analytics project focused on transforming raw car sales data into a clean, structured dataset and developing an interactive **Power BI dashboard** for business analysis.

The project covers data preparation, SQL-based transformation, data validation, analytical modeling, and visualization.

## 🛠️ Technologies

* **PostgreSQL / SQL** — Data storage, cleaning, transformation and validation
* **Power BI** — Dashboard development and visualization
* **Power Query** — Data preparation
* **DAX** — KPI calculations and analysis
* **CSV / Excel** — Source data

##  Workflow

```text
Raw Sales Data
      ↓
PostgreSQL
      ↓
Data Cleaning & Transformation
      ↓
Data Validation & Modeling
      ↓
Power BI
      ↓
Interactive Dashboard
```

##  Dashboard

The Power BI dashboard provides insights into:

* Sales and revenue performance
* Vehicle makes, models and types
* Sales by region and county
* Lead sources
* Sales representatives
* Fuel types and transmission
* Customer information and ratings
* Payment and delivery status
* Delivery performance

### Key KPIs

* Total Cars Sold
* Total Revenue
* Delivery Rate
* Average Customer Rating
* Sales Performance
* Delivery Status

##  Data Model

The project uses a structured model with a central **sales fact table** and supporting dimensions for areas such as:

* Customers
* Vehicles
* Locations
* Dates

This structure allows the Power BI dashboard to efficiently analyze sales across different business dimensions.
